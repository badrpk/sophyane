The authoritative starting tree includes uncommitted Mode-6 observations,
sessions, read-only execution, guarded handoff and campaign code. Preserve it.

## Boundaries

Intelligence supplies untrusted proposals. Canonical authority remains
codex_cli then nifdu_browser; local_gguf is read-only. Truth comes from a
host-configured independent verifier with frozen test/benchmark policy.
Campaign attempts cannot supply evidence or acceptance gates. Missing verifier,
RED, holdout, regression, scope, authorization or measured gain fails closed.
RED_UNAVAILABLE receives no genuine-RED credit. Rejections never advance the
accepted baseline. Level 4 requires sustained gains on versioned meta benchmarks.

## Runtime

A bounded observation bus feeds a persistent deduplicated weakness ledger.
Sources include Mode 6, runtime/tests/providers, performance, benchmarks, user
friction, SLI and diagnostics. Existing Mode-6 ledger handoff also publishes to
this bus; it never applies edits. A default-on daemon supervisor owns bounded
controller ticks, process locking, interruptible waits and clean shutdown.

pressure suspend heavy work. Missing optional sensors require no Termux API.

## Pipeline

ResourceSnapshot and injectable ResourcePolicy choose OBSERVE_ONLY, LOCAL_LIGHT,
LOCAL_DEEP, INTERNET_RESEARCH or CLOUD_REVIEW. Scheduler selects bounded fair
opportunities with retry deadlines and cloud budget gates. Qwen scouts; Spark
critiques. Routing supports qwen, spark, both sequential orders, both, skip_local
and escalate. Competence starts without historical benchmark assumptions and is
updated only from externally measured outcomes by task.

A host-owned experiment registry selects deterministic argv checks, never model
shell text. Baseline and candidate are isolated snapshots of current file bytes.
Frozen tests run against baseline (repeated genuine RED), candidate focused GREEN,
holdout and regression. Diff scope, protected paths, test weakening, source
changes, fingerprint stability and growth are mechanically checked. Cloud receives
compressed evidence only after pre-verification, can reject/request evidence or
approve/propose replacements, and cannot certify tests. Authorized replacements
are applied only to the candidate and re-verified. Controlled promotion checks
that live baseline bytes have not changed before replacing approved files.

SLI performs bounded targeted discovery only for a grounded selected weakness
while online; source-bearing ResearchClaims remain untrusted and enter the same
reproduction pipeline. No research claim can apply or promote code.

Every stage records serializable evidence. Operational counters and versioned
capability/meta measurements distinguish machinery from observed improvement.
Unavailable models, policy, experiments or budgets cause deferral with backoff,
not fabricated successful evidence. Duplicate/no-gain patches, protocol failures,
protected changes and holdout/regression failures fail closed.
